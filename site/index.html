How to read this fairly

  • Same moment, same head start. Both forecasts are saved in the same run. "24 h ahead" means what you could have seen on Yr and WeatherNext 24 hours before the weather happened.
  • Yr has a home advantage. For the first 2–3 days, Yr's forecasts are corrected using measurements from Norwegian weather stations, including many of these ones. WeatherNext is not. That's fair if you ask "which is best for Norway today?", not if you ask "which model is better in general?".
  • WeatherNext averages many possible outcomes. Its average (solid orange) smooths out extremes, which tends to lower the average error. The dashed line shows its median instead.
  • "Too close to call" means the 95% uncertainty range of the difference still includes zero. Days are the unit: errors from nearby stations on the same day are not independent.
  • A naive guess sets the bar. "Same as before" predicts the value measured at the same time of day on the latest day already known when the forecast was made. A useful forecast should beat it; skill above zero means it does.
  • Station measurements vs forecast grids. A forecast describes an area; a station measures one spot. Both models face the same challenge.
